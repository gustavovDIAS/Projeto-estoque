Este Programa é um controle de estoque (SCES)
por enquanto o estoque ja possui 2 produtos, 

contem um menu interativo que você pode remover ou adicionar um novo produto ; 
também pode buscar o produto pelo ID ;
Alterar as quantidades desse produto ;
Visualizar o Status do estoque e com um aviso de falta do produto caso fique com menos de 5 unidades
É muito pratico de usar e tem uma boa organização e está muito harmonioso, feito no Vs code em Python.
